# Spanish glossary (Latin American Spanish) for es/ pages

Use these terms consistently. Register: clear, neutral Latin American Spanish for Portland families (usted, not vosotros; no Spain-only vocabulary). Keep sentences short and plain.

|---|---|

| immersion program | programa de inmersión |
| Spanish immersion | inmersión en español |
| whole-school immersion / whole school | escuela de inmersión completa / escuela completa |
| strand (program within a school) | programa paralelo (*strand*): give the English term in italics on first use per page |
| single strand / two-class strand | un solo grupo por grado / dos grupos por grado |
| class (section) | grupo (salón de clase) |
| neighborhood program | programa del vecindario |
| neighborhood school | escuela del vecindario |
| attendance area / boundary | zona de asistencia / límites de la zona |
| rightsizing | reorganización escolar (*rightsizing*) |
| Scenario A / B / status quo | Escenario A / B / situación actual |
| school closure / consolidation | cierre de escuela / consolidación |
| receiving school | escuela receptora |
| lottery (enrollment lottery) | sorteo (de inscripción) |
| application / offer / waitlist | solicitud / oferta / lista de espera |

Names stay in English: Portland Public Schools (PPS), school names (César Chávez, Lent, Atkinson…), Bridger Creative Science, PSU Population Research Center, document titles (in italics, as published), "pps-explorer", "Save PDX Schools".

Languages in tables: Spanish → Español, Mandarin → Mandarín, Japanese → Japonés, Russian → Ruso, Vietnamese → Vietnamita.

Numbers: keep the English format (1,586; 57%; 0.8 millas). Miles stay miles (millas). Dates: "6 de octubre de 2026". School years: 2025-26.

Quotations from English documents and meetings are translated into Spanish. Each page says so once, near the top.
